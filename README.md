# Robinson Stripe MCP

A hosted MCP server that lets Chris Robinson's AI agents run his Stripe accounts safely — for every project, with
Appliance Desk as the first. Previews before changes, confirmation before money moves, keys that never pass through an
AI, small results that don't burn an agent's context, and a command-line tool (`rstripe`) for agents that can't add a
connector.

**Status:** plan only; no code yet. Start at [`docs/START-HERE.md`](docs/START-HERE.md). AI agents: read
[`AGENTS.md`](AGENTS.md) first.
