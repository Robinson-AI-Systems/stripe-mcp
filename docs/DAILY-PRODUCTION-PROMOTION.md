# Daily production releases and low build cost

Development PRs target main. Only the scheduled daily promotion workflow writes live. Its primary attempt is 00:01 America/Denver (12:01 a.m. local time, including daylight saving changes). Because GitHub may delay or silently drop a schedule event, **00:17 and 00:43 Denver** are same-night missed-trigger recovery windows, not additional releases. Every attempt invokes the same exact-main six-check gate and atomic fast-forward with a dated Colorado-day tag. A successful promotion consumes the day marker, so later attempts skip even if development advances main; unchanged heads also skip. Failed/missing checks, divergence and consumed day markers refuse release. No manual dispatch, no force-push fallback.
