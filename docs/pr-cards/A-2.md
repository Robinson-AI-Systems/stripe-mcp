## Build contract

- `src/db.js`: export `SCHEMA_TABLES`, `createDb(sql?)`, `initSchema()`. Queries go through the supplied tagged SQL function or a lazily created Neon client; lack of `DATABASE_URL` gives a clear configuration error without preventing module import.
- Create the seven exact approved tables: `stripe_accounts`, `oauth_clients`, `oauth_codes`, `oauth_tokens`, `login_attempts`, `change_log`, `one_time_secrets`.
- Every table and index is `IF NOT EXISTS`; no destructive migrations, customer records or production credentials. Passwords and tokens never have plaintext columns. The owner-configurable money limit starts at the approved safe 50,000 cents but B-1 remains its owner gate (IN-05).
- `test/helpers/fake-db.js` mirrors schema initialization; existing generic contract still passes.
- `tests/db/schema.test.js`: real PostgreSQL table set, repeat initialization, hashed-token columns, mode/profile defaults, live disabled, encrypted key slots, expiration indexes.
- `tests/unit/schema.test.js`: fake idempotence, missing SQL function refusal.
- No tool-catalog tools, Stripe API calls, MCP routes, money operations or live toggles in this card.
