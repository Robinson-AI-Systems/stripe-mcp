## A-4a — SDK wrapper (PR #13)

Build `src/stripe/client.js`: export `STRIPE_API_VERSION`, `makeStripeClient({key,mode})`,
`idempotencyKey(ctx,tool,args)`, `listAll(listFn,params,{max})`.
- Only production import of Stripe SDK lives in this file. No hand-built Stripe request bodies.
- Any Stripe write (in future cards) must use scoped, stable idempotency keys: account, mode, tool and canonical arguments; preview/confirm/fields/detail do not influence it, ten-minute bucket unless explicit requestKey (hashed and stable across buckets).
- Live credentials refused outside production, even if mode says live. Key/mode mismatch refused.
- List pagination bounded and transparent; malformed or stuck cursors fail rather than silently truncating.
- Tests: `tests/unit/client.test.js` for version, key/mode safety, deterministic retries, canonical arguments, bounded pagination; `tests/mock/client.test.js` invokes SDK subscriptions.create with nested `items` against isolated stripe-mock.
- `npm run check`, `npm test`, `npm run test:mock`, aggregate `ci` green at exact head.
