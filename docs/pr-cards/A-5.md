## A-5a — encrypted primitives and database contract (PR #15)

- `src/core/crypto.js`: fail-closed AES-256-GCM; requires `TOKEN_ENCRYPTION_KEY` as 32 base64-decoded bytes when invoked; no fallback, error never includes key/ciphertext, domain-bound authenticated data.
- `src/keys.js`: `createKeyStore`, provider-verified test account, only restricted/secret test keys accepted, ciphertext persisted under `stripe_accounts`; `loadKey` server-only. Returns only account, label, key kind and last four characters.
- `src/core/one-time-secrets.js`: encrypted issue with opaque ID and ten-minute expiration; returns setup link only; reveal once after DB atomic delete (A-5b must put owner authentication in front of this).
- `src/db.js`, fake DB: `saveTestKey`, `getEncryptedKey`, `addOneTimeSecret`, `consumeOneTimeSecret`; no plaintext columns or schema migration.
- Unit tests: auth-context mismatch, tampering/wrong key, missing config, no secret in metadata, test-only mode, fake provider account verification, one-time-only read.
- Real PostgreSQL tests: encrypted-at-rest and key kind, live disabled, atomic one-time reveal under concurrency.
- `npm run check`, `npm test`, `npm run test:db`, `npm run test:mock`, and exact-head aggregate `ci` green.

## A-5b — protected owner setup, permission probes, read-only tools (PR #16)

- `api/stripe/setup.js`: authenticated HTML form on server only; uses owner passphrase and existing login lockout, csrf protections, preview/live restriction, accepts keys without sending them through AI chat, verifies account and probes key permissions using harmless read calls. Show only last four and friendly restrictions.
- One-time secret link can reveal only behind the passphrase and deletes atomically on first view or expiry. Never return a secret through MCP or an API tool.
- Read-only `stripe_whoami` and `stripe_list_accounts` tools for connected authorized users; ensure scoped dispatch via MCP, not direct calls bypassing permissions.
- Tests across page, one-time flow, fake Stripe and isolated PostgreSQL. Update TOOL-CATALOG, OWNER-GUIDE, ARCHITECTURE and GO-LIVE. Close A-5 only after full verified CI, without pretending a real owner account is configured.
