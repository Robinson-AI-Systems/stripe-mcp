- `src/core/write.js`: generic `defineWrite` lifecycle: read actual state, safe preview, no action on `dryRun` or missing `confirm`, idempotency, write intent recorded before apply, read-back confirmation, inverse metadata and audit.

- The registry remains read-only; no user-triggerable Stripe write exists. CI check/unit/db/mock + aggregate `ci` green at exact head.
