## Build contract
- Detect object ownership through metadata (including `agreementId`, `rentalLineId`, `rdf_record_id`) or the linked customer's metadata.
- Read results may expose `appRecord` metadata and never deny a read.
- Refuse app-owned subscription/price/customer changes with the owning app, record identifier, reason, and owning screen. Only explicit `outsideApp:true` overrides a known-owned target.
- An unknown customer ownership check fails closed even if `outsideApp:true` is supplied.
- App-owned refunds are allowed under `confirm:true` only with the normal B-1 owner money approval; preview clearly says the rental app observes the refund.
- Never let the exception bypass other guards, confirmation, account/mode isolation or audit.
- No live keys, writes on remote Stripe, app repo changes, or new MCP tools.
