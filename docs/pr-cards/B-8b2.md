## Build contract
- `stripe_revoke_connection`, `stripe_set_default_account`,
  `stripe_set_money_limit`, and any supported `stripe_disable_live`
  must be tied to an independently authenticated **owner-only setup action**,
  with exact account/target/old/new preview, CSRF, origin and lockout.
- Start with narrow TEST-mode account administration that does not involve moving
  money. Do not expose account-mutating handlers via MCP until server-side
  owner-authenticated authorization (not an AI-supplied flag) is complete.
- Enforce per-account locking, stale-state/read-back verification, audit log,
  retry/idempotency and the seven write-contract cases for each exposed write.
- `read_only` cannot invoke writes even by tool-name guessing or future meta tools.
- A money-limit change must not silently alter the approved $500 default or
  exempt any transaction from mandatory independent owner approval. If this
  would require new owner consent beyond IN-05, keep the change unavailable
  until the authorization is explicitly granted.
- No live key, live Stripe write, real money, paid infrastructure or other repo.
- Keep B-8c owner money-out authorization separate and disabled.
