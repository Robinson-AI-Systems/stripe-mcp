## Acceptance
- Preview only for an actual TEST-connected account, not already default;
  stage a 10-minute one-use owner intent with previous default snapshot.
- Independently authenticated final confirmation, explicit checkbox, CSRF,
  strict same-origin and existing lockout. Neither an AI argument nor a
  leaked intent alone can alter settings.
- PostgreSQL transaction advisory lock protects default updates from races;
  prior-default mismatch, replay or expiry fails closed. Exactly one
  `stripe_accounts.is_default` set TRUE; one audit inserted per success.
- Existing token account scopes unchanged, no Stripe payments, live enable,
  keys, money-limit change or public MCP write tool.
- Fake unit tests cover page security and stale states; localhost isolated
  PostgreSQL tests cover two competing server instances, one winner/audit.
- `npm run check`; exact-head full CI; security self-review and drift B;
  ARCHITECTURE, STATUS, owner guide, catalog, GO-LIVE, index updated.
