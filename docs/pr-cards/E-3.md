## Drift check B — permission and integration boundary

Provider-backed monetary billing credit semantics are not "free": an E-3 grant may reduce future customer invoices and a void can claw back benefits. They must never be treated as ordinary harmless metadata writes or inherit a developer-only permanent $0 cap. Any insufficient current user delegation fails closed without dropping the capability. Meter event ingestion is asynchronous and is not a verified invoice total.
