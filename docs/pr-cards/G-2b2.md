## Drift check A
| Planned assumption | Verified provider/runtime | Correction |
| --- | --- | --- |
| Any HTTPS fetch is safe | Untrusted URLs may resolve to private/link-local IPs | IPv4 public DNS only, pin verified address into TLS request, recheck each redirect |
| Google Drive share page returns raw file | Viewer links return HTML, public file may require download URI | Normalize shared Drive IDs, reject HTML/login/confirmation and oversized responses |
| Upstream declares accurate PDF MIME | Remote content type may be octet-stream or deceptive | Accept only PDF/PNG/JPEG by magic signature, file name extension must match |
| Upload result means completed provider file | Stripe may reject multipart or return uncertain receipt | Use pinned SDK files.create, then independent files.retrieve ID/size/purpose |
| Upload equals final submission | Stripe disputes require a separate update/submit | Never attach, accept, submit or update any dispute from this tool |

## Build contract
- `src/stripe/evidence-source.js`: HTTPS only, no credentials/fragment/port/
  IP literal, strict host validation, DNS resolve all IPv4, pin public address,
  deny RFC1918/link-local/bogon, verify TLS hostname, max two HTTPS redirects
  with re-resolution, 15-second transport timeout, 10 MiB bounded stream,
  validate length and PDF/PNG/JPEG magic, generic errors.
- `src/tools/evidence-upload.js`: standard defineWrite with TEST provider
  account verification, preview/confirm/idempotency/audit. No URL query string or
  bytes in preview/results. Upload via Stripe native files.create with
  purpose=dispute_evidence; independent files.retrieve verifies ID, purpose,
  size, filename and TEST mode.
- Returns verified file ID only, explicitly evidenceSubmitted:false.
  No money, LIVE, other account key, arbitrary local path, or file download link.
- Tests: public DNS/SSRF/safe redirects/bounds/MIME and guarded upload cases,
  standard unit and Stripe mock, registry/index, 5 exact-head CI gates.
- No connected real Stripe account exists, so mock success ≠ live provider proof.
