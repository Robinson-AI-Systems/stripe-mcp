## Implementation

- Additive `known_apps` table, seed exactly once, optimistic revision, exact active-account binding with account FK presence; future projects are data rows with documented fields and no new custom code.
- Explicit per-account `app_profile_account_scope`: new accounts remain `legacy` for conservative B-3 protection until owner binds each application and individually confirms migration.
- On scoped accounts, only matching bound active profiles identify ownership. A second app with different marker works; overlapping active app markers are **unknown and denied**, never guessed or double-counted.
- Registry failure or missing customer ownership snapshot remains **fail closed**, including when `outsideApp` is requested.
- Actual owner setup form requires CSRF, administrator passphrase, exact TEST account ID, profile revision and owner checkbox. Separate explicit scope consent; refuses activation if no app bound. TEST only.
- Native tool reads and guarded writes `project_list_profiles`, `project_get_profile`, `project_bind_profile_account`, `project_enable_scoped_ownership`; full profile only for writes, selected TEST account verified.
- Preserve independent money-out approval and LIVE OFF. Profile data never authorizes application money mutations.
