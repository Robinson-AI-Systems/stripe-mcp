## Build contract
- src/dev/forwarder-delivery.js exports verifyOriginalTestEvent, selectOriginalTestEvents,
  deliverOriginalTestEvent (internal-only). No fake events or LIVE access, no write endpoints.
- Stripe selected-account SDK events.list: GET /v1/events with created.gte, types<=20, limit 5,
  starting_after; independently GET /v1/events/:id. Exact IDs path max five.
- Original TEST data transmitted byte-exact with Stripe-Signature, official HMAC. Reject
  redirect/no-follow, private/metadata IP, TLS mismatch, oversized payload, response overflow, timeout.
- Native HTTPS request uses original verified hostname, TLS servername and Host, pinned resolved
  public address, no redirects, one socket. Do not echo signatures or full event bodies in MCP.
- V-4c2 owns guarded dev_forward_events dispatch and durable retry/receipt reconciliation;
  V-4c1 MUST NOT claim users can send events via MCP yet.
