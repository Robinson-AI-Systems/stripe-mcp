## Safeguards

All operator reads use original wrapped native tools, no raw provider evidence body, hosted secret or LIVE credential. Only native `dispute_save_evidence` and `webhook_add_events` may write, each through its original independent `defineWrite-v1` app guard/audit/idempotency/readback; root workflow SHA-256 is NOT an owner grant, must not submit dispute, accept dispute, enable LIVE or copy catalog. No endpoint secret/URL path returned. Event undelivered scan is globally scoped, never evidence of a specific endpoint's receipt. All new source/live acceptance is separate queued; no manual promotion, autonomous money-out, LIVE or unapproved fixtures.
